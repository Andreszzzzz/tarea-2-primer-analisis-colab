## Tarea 2 — Primer análisis en Google Colab

- **Notebook:** `tarea2-analisis.ipynb`
- **Dataset:** Bike Sharing Dataset (`day.csv`), UCI Machine Learning Repository.
- **Fuente:** https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
- **Objetivo:** describir y estimar el total diario de alquileres (`cnt`) a partir de variables de calendario y clima.
- **Contenido:** lectura desde fuente pública, parseo, auditoría de faltantes/duplicados/reglas de plausibilidad, decisiones de depuración, gráficos, baseline y regresión lineal evaluados con MAE.

**[URL de Google Colab:](http://colab.research.google.com/drive/1JMR9B3RKeFg6Z_zmjITEvttj38n0ctTA#scrollTo=dcf0fd9c)**

Este proyecto desarrolla un análisis exploratorio y predictivo
del conjunto de datos Bike Sharing Dataset.

Se estudian los datos de alquiler diario de bicicletas y se
construye un modelo de regresión para estimar la cantidad
de alquileres diarios.
